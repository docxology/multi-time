# Abstract

Multi-Time provides data loading, validation, statistical diagnostics,
transformations, forecasting, and evaluation for indexed time series.
It wraps sktime estimators behind a project registry and exposes both a
Python pipeline and task-specific command-line demonstrations. A scripted
synthetic example fits a last-value baseline to a daily series and evaluates
it on a chronological holdout. The report and plot document the workflow
under the repository's locked dependencies.
